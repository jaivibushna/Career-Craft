SQL Interview Questions for Freshers

Learn the most frequently asked SQL interview questions with simple explanations.

1. What is SQL?

SQL (Structured Query Language) is a standard language used to create, retrieve, update, and manage data in relational databases.

2. What is the difference between DELETE, TRUNCATE, and DROP?

DELETE TRUNCATE DROP
Removes selected rows Removes all rows Deletes the entire table

3. What is a Primary Key?

A Primary Key uniquely identifies each record in a table. It cannot contain NULL values or duplicates.

4. What is a Foreign Key?

A Foreign Key creates a relationship between two database tables.

5. Difference between WHERE and HAVING?

  • WHERE filters rows before grouping.
  • HAVING filters grouped results after GROUP BY.
